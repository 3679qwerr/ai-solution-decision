## 对用户要求的覆盖

| 要求 | 实际验证 | 限度 |
|---|---|---|
| 目录与引用完整 | 文件与路径检查、安装后再查 | 不是所有宿主的加载验收 |
| 选型逻辑一致 | 17 个 oracle + 独立门槛变异 | facts 由外部分析填写，未测试自然语言解析 |
| 不必要 Agent 能识别 | 规则、数值、检索、固定 Workflow 的回归 | 不能等同 LLM 在真实需求上的判断成功率 |
| 证据不足不编造数据 | 未知输入保留 unknown；证据字段/来源/模拟角色检查；人工评分规范 | 不能自动检测全部语义造假，模型行为未实测 |
| 成本可运行 | 手算 oracle、边界、两例 CLI 与复算 | 模拟价格，非供应商报价或真实 TCO 证明 |
| 关键产品指标 | 五类类别、定义、分母、窗口、source 与 owner 字段验证 | 内容是否有效需人工与真实业务数据 |
| 权限、异常、降级 | 必填字段变异、工具注入类型拒绝、重大风险人工否决 | Skill 不是运行时沙箱；未执行真实副作用故障注入 |

## 模型对照状态

**not_run**。本轮没有配置用于隔离、可复现对照的模型调用接口；未发现已配置的常用模型 API 环境变量。没有将当前对话中作者写的案例或合成测试响应伪装成模型试验。

已交付 [模型对照协议](../ai-solution-decision/evals/PROTOCOL.md) 和 prepare/grade 工具：相同题目与格式、隔离会话、固定模型与预算、多次配对、真实 usage／轨迹、独立盲评、保留失败、重大安全失败否决。prepare 和 grader 的功能用合成工件测试过，**合成工件只验证评测器，不形成模型效果结论**。

当前不能报告：Skill 增益、触发 precision/recall、模型成功率、真实成本差、用户留存、转化或收入变化。上述指标为 unknown／not_run。

## 仍需验证的事项

- 用户痛点、付费意愿、业务因果与样本量依据尚无一手研究；两个产品都是示范 brief。
- 门槛脚本不读自然语言、不能验证用户陈述是否真实，也不能替代架构和数据保护评审。
- 自动结构评分无法证明引文真实、实验设计合理或授权已经发生；人工评分与轨迹证据不可省略。
- 作者设计了 oracle 和实现，测试集不是独立盲测。新模型或宿主应新增未见过的任务、攻击和失败族。
- 成本模型没有条件到达率、缓存、并发、排队、阶梯价、税或全部企业集成项；延迟和单位经济需另测。
- 未完成真实宿主触发、权限隔离和外部写入恢复测试，不称 production_ready。
