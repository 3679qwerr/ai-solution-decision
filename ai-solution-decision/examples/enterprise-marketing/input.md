# 企业智能营销：模拟输入

**数据声明：本文件全部需求、规模和参数均为模拟，无真实企业或客户信息。**

设想一个 B2B 营销团队要从已授权 CRM 线索中筛选跟进对象，查产品手册，生成有依据的邮件草稿，由销售审核后自行发送。当前做法是人工筛选、查手册和复制模板；痛点假设是重复查找和草稿修改耗时，尚无真实访谈或耗时日志。

使用者为销售运营与销售，付费者为销售负责人。希望缩短准备时间且不增加错误承诺。线索筛选字段和流程固定，第一版不需要自主探索客户或更改营销预算。企业文档有租户权限；不允许模型直接访问完整 CRM 或发送邮件。计划先离线演示，不连接真实 CRM 和邮箱。

模拟月任务 1,000 次，人工复核每次 2 分钟、人工时薪 USD 24；检索每次工具费 USD 0.001；草稿每次 1,800 输入与 400 输出 token。所有 API 价格只用于情景计算，不对应实际模型报价。预算、延迟和业务成功率尚待确认。请给 AI 必要性判断、方案比较、工作流、MVP、指标和实验。
