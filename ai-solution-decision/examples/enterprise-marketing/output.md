# 企业智能营销：完整决策包

**模拟案例。本文没有真实转化提升、客户采用或生产运行结果。所有阈值为拟议目标，所有成本参数为模拟。**

## 决策与证据

推荐“规则筛选 + 权限内检索 + RAG 草稿 + 固定审批 Workflow”。营销任务有固定依赖，MVP 无须让模型自主决定工具与发送。当前状态是 needs_evidence：可做离线原型，尚不能确认生产可行性。

| 主张 | 证据角色 | 来源／缺口 |
|---|---|---|
| 筛选字段和流程固定；只生成草稿 | simulated | [模拟输入](input.md)，未做实际流程观察 |
| 销售反复查资料耗时 | simulated | 待访谈和脱敏计时；不能直接计算节省收益 |
| 企业文档有租户 ACL | simulated | 待检查真实 ACL 与服务端过滤实现 |
| 缩短准备时间可能增加跟进容量 | inferred | 基于价值链，仍受线索质量与销售产能影响 |
| 实际成功率、收入增量、模型价格 | unknown | 未运行用户实验，也未选择供应商 |

使用者任务是准备可信跟进材料；付费者购买的是销售准备效率与风险控制。不能把邮件生成量等同于有效机会或收入。先测当前人工处理时长、草稿错误和不用工具的完成率。

## 技术取舍

| 候选 | 质量 | 成本与维护 | 延迟／稳定性 | 隐私 | 结论 |
|---|---|---|---|---|---|
| 人工+模板 | 基线 unknown，可控承诺 | 人工费待测，模板需更新 | 依赖人员，时间待测 | 现有授权边界 | 保留对照与兜底 |
| 规则 | 适合线索筛选，不能完成开放写作 | 规则可审计，例外需维护 | 确定性，实测待做 | 最小字段 | 用于硬规则与资格判断 |
| 传统算法 | 排序可能有价值，但无标签／收益证据 | 标注与漂移成本未知 | 离线验证未做 | CRM 数据隔离 | P1 前先看是否真的需要学习排序 |
| 检索 | 能定位材料，不能直接完成草稿 | 索引与 ACL 维护 | 召回、超时待测 | 检索前做租户过滤 | RAG 的对照组 |
| 直接 LLM | 表达灵活，产品事实无保证 | 少一层索引但有复核成本 | p95 unknown | 仅传最小脱敏上下文 | 只做写作对照，不负责产品承诺 |
| RAG+Workflow | 可能提高可追溯性，尚未验证 | 比检索复杂，须测成功任务成本 | 固定步骤便于恢复；p95 unknown | 引用继承 ACL | 推荐候选 |
| 单／多 Agent | 动态规划的收益未证明 | 增加规划、通信、审阅成本 | 失败路径更多 | 增加工具权限面 | 拒绝进入 MVP |

不能用“多 Agent 分成销售、文案、审核三个角色”证明需要三个自治执行者。当前审核是人工责任，生成者不能自批草稿。

## 用户流程与执行设计

用户选择已授权线索与材料版本 → 规则校验并解释排除原因 → ACL 检索 → 生成带来源草稿 → 合同与事实检查 → 人工查看证据、编辑并导出 → 完成。没有自动发送能力。

| 工具／阶段 | I/O 与权限 | 异常、恢复与验收 |
|---|---|---|
| `select_leads` | 脱敏 lead_id 与批准字段 → 候选；只读固定租户 | 缺字段跳过并列原因，规则结果由代码核验 |
| `search_docs` | 租户、query、版本 → 可见片段与 doc_id | 无证据拒绝产品事实生成；暂时失败时含首试最多 2 次尝试 |
| `draft` | 片段+模板 → 草稿与 claim-source 映射 | schema 无效记失败，可新建 1 次生成尝试；不静默补事实 |
| `export_draft` | 经用户确认的 version → 本地草稿文件 | 不具备邮箱权限；重复导出使用 run_id+version 幂等键 |

状态：created → validating_input → retrieving → drafting → validating → waiting_approval → exported；无证据到 partial，超时到 failed，拒绝或用户取消到 cancelled。审批等待拟议 24 小时后保留草稿并结束，不能自动同意。生产若增加发送，须新增具体收件人、内容版本、渠道与授权有效期，并在发送超时时先查回执，禁止盲重发。

拟议停止线：单任务计算 30 秒、工具总尝试 6 次、模拟模型/工具预算 USD 0.05、连续 2 次不可恢复错误或用户取消立即停。该预算不含人工和固定费，必须与总成本分开。日志保留 run_id、文档版本、attempt、费用和状态，不保存完整客户内容；真实保留期限待企业政策确认。

## MVP 与验收

| 优先级 | 功能与角色 | 验收 |
|---|---|---|
| P0 | 产品准备脱敏任务与人工对照；工程实现规则、ACL、草稿证据与导出 | Given 不可见文档，When 检索，Then 片段不进入模型上下文 |
| P0 | 工程提供错误与重复导出处理；销售验证草稿 | Given 无相关材料，When 生成，Then 不生成无依据产品承诺并提供人工出口 |
| P0 | 产品记录用时与验收结果 | Given 一批分配任务，When 有失败和超时，Then 均计入任务分母 |
| P1 | 经标签与价值验证的线索排序、批量复核 | 仅在 P0 证明效率价值后设计 |
| 暂不做 | 自动发送、爬取私人客户内容、多 Agent 自主营销 | 不包含对应工具权限 |

依赖：获批资料、ACL 规范、销售验收标准与数据 owner。可先用 30 个**拟议练习任务**检查工具流程；这不是统计充分的样本量或已跑过的实验。

## 指标与实验

| 类别 | 定义／数据源 | 窗口与 owner | 拟议目标／停止线 |
|---|---|---|---|
| task | 全部有效分配中经销售盲审接受的草稿比例；任务事件 | 每轮离线任务，产品+销售 | 先测基线，质量不劣于人工；具体容忍界限待定 |
| business | 每任务人工准备分钟；计时日志 | 操作员周，销售运营 | 降低用时是待检验假设，不报提升百分比 |
| cost | 全尝试、工具、人工成本 / 验收成功任务；费用台账 | 每轮和每月，财务/产品 | 上限待预算批准；0 成功时 unknown |
| risk | 未授权文档进入上下文数、无依据承诺数/审核主张数 | 每轮，安全+销售 | 未授权披露为 0；发现一次暂停 |
| operations | 不含审批与含审批两种 p95；重复导出率 | 每轮，工程 | 计算 p95 拟议 ≤15 秒；实测 unknown |

离线配对：同一脱敏任务随机顺序比较人工+模板、检索+人工写、直接 LLM、RAG 草稿；盲审事实性与可用性，同时测人工时间。Skill 对照另按 evals 协议，不能把本产品消融混成 Skill 增益。未来线上以团队/企业随机，预注册有效机会指标、污染控制与最小可检测差异；样本量待真实方差。

成本见 [输入](cost-input.json) 与 [计算结果](cost-output.json)：模拟月费 **USD 1,056.375**，12 月 TCO **USD 16,276.5**（含一次集成与退出），成功任务成本 unknown。未包含税、并发排队或未知企业集成项，不能据此声称 ROI 为正。

## 决策日志

产品负责验证耗时痛点与预算，工程验证 ACL 和失败恢复，销售定义不可接受承诺。若固定流程失败主要来自需动态选择系统且工具齐备，再试有界单 Agent；仅在独立子任务的净并行收益和合并控制有匹配对照后讨论多 Agent。真实预算、模型选择、隐私协议、效果基线未确认前停留在离线设计阶段。
