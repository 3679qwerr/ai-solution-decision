# 小满桌面伙伴：模拟输入

**全部为模拟产品设想，不描述实际“小满”实现或用户实验。**

面向希望获得轻量陪伴与任务帮助的成年桌面用户，提供桌面角色、用户主动聊天、专注计时与可手动调用的任务 Skill。付费者与使用者暂定同一人；商业模式未验证。

希望角色能适时问候，但不能持续截屏、读取聊天记录、分析摄像头或默认记录敏感信息。用户可手动选择“专注／可打扰／休息”，本地空闲时长仅作为可选信号；心情由用户自报，不进行心理诊断。第一版任务只有本地计时、用户选择文本的摘要和待办草稿，不自动发消息或改日历。

主动提醒按用户许可、静默时段、冷却时间与每日上限决定，分支固定。可以可选接入 LLM 进行自由聊天，网络和隐私可行性待确认。模拟月 600 次聊天，每次 1,000 输入和 300 输出 token；不提供真实留存、付费或帮助度数据。请输出主动交互与任务能力的最小方案，并说明是否需要 Agent。
