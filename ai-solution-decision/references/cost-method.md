# 成本计算口径与输入说明

计算器只做给定参数的算术，不抓价格、不推荐供应商、不预测收入。示例输入全为 simulated；实际报价用 estimate，完整的真实计量才用 observed，不把估计与观测混成真实账单。

## 输入

| 字段 | 单位／含义 |
|---|---|
| currency | 显式币种，如 USD；同一输入必须同币种，无换汇 |
| monthly_tasks | 每月任务数，非负整数，含失败与超时任务 |
| fixed_monthly_cost | 每月固定费，按实际口径包含维护、托管、索引等 |
| integration_cost / exit_cost | 一次集成成本、期末退出迁移成本 |
| human_minutes_per_task / human_hourly_cost | 每任务平均人工分钟与每小时人工费 |
| task_success_rate | 任务验收成功率，0–1 或 null；不是模型请求可用率 |
| stages | 每任务执行的阶段列表，可通过 calls_per_task 表示扇出 |

阶段字段：name 唯一名称；calls_per_task 为非负整数；input_tokens/output_tokens 为每次尝试 token；input_per_million/output_per_million 为每百万 token 价格；tool_cost_per_call 为每次工具费；retry_probability 为再次尝试概率 q；max_attempts 为含首试的上限 n（1–10）。确定性零费用阶段可填 0，不省略价格字段。

## 公式与限制

平均尝试数 `A = 1 + q + ... + q^(n-1)`，假设概率恒定且独立。每任务阶段费 = 调用数 × A × [(输入 token × 输入单价 + 输出 token × 输出单价)/1,000,000 + 工具单价]。所有阶段费与人工费求和，再乘任务量，加固定月费。

12/36 月 TCO = 一次集成费 + 对应月数 × 月费 + 一次期末退出费。不计折现或通胀。运营成功任务成本 = 月运营费 /（月任务量 × 成功率），成功率未知、为 0 或任务量为 0 时输出 null；该指标不摊销集成和退出。TCO 另报，避免混淆。

模型简化为每任务尝试所有阶段：失败后短路、条件分支、cache、不同重试 token、人工抽检采样、并发容量、队列、税和阶梯报价需修改场景或另建模型。调用量敏感性为 0.5×/1×/2×；仍保留固定费。真实预算线应包含未建模费用并按风险留余量，不把模拟结果当授权。

先从脱敏 usage 记录和财务口径校准输入，比较同一成功定义下的候选；没有成功率不能凭便宜的每次调用选胜者。延迟、稳定性、隐私不由此计算器证明。
